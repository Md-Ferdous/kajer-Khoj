# কাজের খোঁজ (Kajer Khoj) — গ্রামীণ দিনমজুরদের জন্য কাজের ওয়েবসাইট

একটি সহজ, দ্রুত-লোডিং ওয়েবসাইট, যেখানে গ্রামের মানুষ (দিনমজুর, রাজমিস্ত্রি, কৃষি শ্রমিক ইত্যাদি)
আজকের কাজের খবর দেখতে পারবেন এবং সরাসরি ফোন করে মালিকের সাথে যোগাযোগ করতে পারবেন। কোনো
অ্যাকাউন্ট বা লগইন লাগে না — শুধু দেখুন আর কল করুন।

ডেটাবেজ বা সার্ভার ছাড়াই এটি শুধু HTML, CSS আর JavaScript দিয়ে তৈরি — তাই GitHub Pages-এ
বিনামূল্যে হোস্ট করা যায়।

## কাজের বিজ্ঞাপন কীভাবে যোগ হয়?

যেহেতু এটি একটি স্ট্যাটিক (database ছাড়া) সাইট, নতুন কাজের বিজ্ঞাপন সরাসরি সাইটে কেউ পোস্ট
করতে পারবে না। এর বদলে দুটো পথ আছে:

1. **মালিক/ঠিকাদার নিজে পোস্ট করেন (WhatsApp বা ফোনে)** — সাইটে "আপনার কি লোক দরকার?"
   অংশে একটি WhatsApp বাটন আছে যেখানে চাপ দিলে আগে থেকে লেখা একটি মেসেজ টেমপ্লেট নিয়ে
   WhatsApp খুলে যাবে। মালিক শুধু ফাঁকা জায়গাগুলো পূরণ করে পাঠিয়ে দেবেন।
2. **আপনি (অ্যাডমিন) সেই মেসেজ পেয়ে ম্যানুয়ালি যোগ করেন** — `assets/js/data.js` ফাইলে
   `JOBS` তালিকায় একটি নতুন এন্ট্রি যোগ করে GitHub-এ পুশ করলেই সাইটে দেখা যাবে (২-৩ মিনিটের
   মধ্যে)।

এভাবে মালিকরা মনে করবেন তারা "নিজে পোস্ট করছেন" (সহজ, টাইপ করার ঝামেলা নেই), কিন্তু আপনি
আসল কনটেন্ট নিয়ন্ত্রণ রাখতে পারবেন যাতে ভুয়া বা ভুল তথ্য না ঢোকে।

## ফাইল কাঠামো

```
.
├── index.html                # পেজের কাঠামো — এখানে হাত দেওয়ার দরকার নেই
├── assets/
│   ├── css/style.css         # ডিজাইন
│   └── js/
│       ├── data.js           # ← এই ফাইলে কাজ/এলাকা/নাম্বার এডিট করুন
│       └── main.js           # data.js থেকে পেজে দেখায় — হাত দেওয়ার দরকার নেই
└── README.md
```

## ১. প্রথমেই নিজের নাম্বার বসান

`assets/js/data.js` ফাইলের একদম উপরে `CONTACT` অংশে আপনার আসল ফোন ও WhatsApp নাম্বার বসান:

```js
const CONTACT = {
  phone: "+8801XXXXXXXXX",
  whatsapp: "8801XXXXXXXXX",   // + বা ০ ছাড়া, শুধু সংখ্যা
  whatsappDefaultMessage: "...",
};
```

`index.html`-এর উপরে হেডারে এবং "সাহায্য/অভিযোগ" জায়গাতেও `tel:+8801700000000` লেখা আছে
সেটাও নিজের নাম্বার দিয়ে বদলে নিন (Ctrl+F / Cmd+F দিয়ে `8801700000000` খুঁজুন)।

## ২. এলাকা ও ক্যাটাগরি নিজের মতো সাজান

- `AREAS` — আপনার এলাকার উপজেলা/গ্রামের নাম বসান।
- `CATEGORIES` — নতুন কাজের ধরন যোগ/বাদ দিতে পারবেন, প্রতিটির একটা ইমোজি আইকন লাগবে।

## ৩. নতুন কাজ যোগ করা

`JOBS` তালিকায় একটি নতুন অবজেক্ট (object) যোগ করুন — উদাহরণ হিসেবে যা আছে সেটা কপি করে
পরিবর্তন করে নিলেই হবে:

```js
{
  id: "job-009",
  title: "কাজের নাম",
  category: "rajmistri",     // CATEGORIES এর id থেকে বেছে নিন
  area: "গোপালগঞ্জ সদর",     // AREAS থেকে বেছে নিন
  wage: 600,                  // টাকা, শুধু সংখ্যা
  date: "আজ",
  people: 2,
  contactName: "মালিক: নাম",
  phone: "+8801XXXXXXXXX",
},
```

পুরনো কাজ শেষ হয়ে গেলে সেই এন্ট্রিটা তালিকা থেকে মুছে ফেলুন।

## লোকালি দেখা (Preview)

```bash
cd kajer-khoj
python3 -m http.server 8000
```

তারপর ব্রাউজারে `http://localhost:8000` খুলুন। (VS Code হলে Live Server extension ব্যবহার
করলেও চলবে — right-click `index.html` → Open with Live Server।)

## GitHub Pages-এ ডিপ্লয়

1. GitHub-এ একটি রিপোজিটরি তৈরি করুন।
2. এই ফোল্ডারের ফাইলগুলো পুশ করুন:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: kajer khoj job board"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
3. রিপোতে **Settings → Pages** এ যান, Source-এ `Deploy from a branch` বেছে নিন, branch
   `main`, folder `/ (root)` সেট করে Save করুন।
4. ১-২ মিনিট পর সাইটটি লাইভ হয়ে যাবে — লিংক ওই একই Pages সেটিংস পেজে দেখাবে।

পরে কনটেন্ট আপডেট করতে চাইলে শুধু `data.js` এডিট করে আবার পুশ করলেই হবে:
```bash
git add .
git commit -m "নতুন কাজ যোগ করা হলো"
git push
```
